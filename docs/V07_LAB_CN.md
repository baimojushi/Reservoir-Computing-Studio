> V0.7.1 对本文第 3 节的视觉语义和第 9 节的遗留项有修订，以 `docs/V071_RELEASE_CN.md` 为准；下表已同步更新。

本版回应 `docs/V07_DESIGN_REVIEW_CN.md` 的审查结论。训练引擎、数据隔离、服务接口、实验数据库和课程数据都没有改动。

## 1. 改了什么

| 范围 | V0.6 | V0.7 |
|---|---|---|
| 实验室主体 | 原生 QPainter 画布，五个“透镜”下拉框 | 单文件网页 `rcstudio/lab_web/lab.html`，五步引导加“我的实验” |
| 承载方式 | 只能在装有 PySide6 的机器上看到 | 应用内嵌（QWebEngineView）；浏览器直接打开（`python -m rcstudio lab`）；无头 Chromium 自动走查 |

## 2. 五步流程

每一步只说一件事、只让人做一个动作、并给出一个看得见的结果。完成动作后顶栏的“下一步”变绿；不做也可以直接跳。

| 步 | 标题 | 动作 | 看到什么 | 带走什么 |
|---|---|---|---|---|
| 1 | 先敲一下 | 点“敲一下”，或点“输入”一行 | 池子亮起再暗下去；热图上一条拖尾；“余波持续 N 步” | 输入结束后池子里还留着痕迹，这就是回声 |
| 2 | 同一下敲击，48 种反应 | 点任意节点 | 48 条曲线里它自己那条；连向它和它连出的线 | 连线随机且不训练；池子把一条输入摊成很多条曲线 |
| 3 | 学习只发生在读出 | 点“训练读出” | 读出线汇向输出；绿色预测线比游标早 6 步；比“原地不动”准多少倍 | 训练 ESN 就是求一组音量，一次求解 |
| 4 | 三个旋钮，改池子的脾气 | 拖旋钮或点预设 | 余波曲线即时变化，灰色虚线是改动前；“不停”时池子自己振荡 | 回声长短、反应快慢、输入力度各管什么 |
| 5 | 自由实验 | 换输入、手绘、开关连线 | 以上全部，读出自动重算 | 自己试 |
| 实 | 你训练的模型 | 在研究工作台点一条实验 | 同一种图画的是真实状态；该模型的回声步数；训练段、验证段、测试段 | 学到的看法可以直接用在自己的模型上 |

第 5 步在应用内提供“用真实数据训练一个”，点击后切到研究工作台。

## 3. 视觉语义约定

| 画面元素 | 含义 | 刻度 |
|---|---|---|
| 节点颜色 | `x_i(t)` 的正负：蓝为正，红为负 | 所有章节不变 |
| 节点亮度与大小 | `|x_i(t)|` | 显示曲线在 0.8 处到顶；`|x| ≥ 0.97` 加白圈表示顶到上限 |
| 深色区域 | 池内：池子本身和“储备池”一行 | 浅色区域是池外的输入与输出 |
| 输入线 | `W_in,i · u(t)` 的大小；正式实验中 `u` 是模型实际收到的标准化输入 | `min(1, |·|)`，固定刻度 |
| 内部连线（开启时） | 源节点此刻送出的 `W_ij · x_j(t)`；颜色为权重正负 | `min(1, 2.2·|·|)`，示范与正式实验同一刻度 |
| 选中节点的连线 | 权重正负与大小，箭头指向接收方 | — |
| 读出线 | `w_i · x_i(t)`：蓝为正向贡献，红为负向，粗细为大小 | 以整段时间内的最大值为准 |
| 读出柱（V0.7.1） | 左柱累加节点正向贡献、正的直连项与基准；右柱抵消负向各项；落点为预测 | 各项、各时刻同一刻度 |
| 余波强度 | “敲”与“不敲”两次运行的 `‖Δx(t)‖/√N` | 整条曲线同一刻度；判定为已观察到衰减、观察窗口不足或窗口内未见衰减 |
| 输出一行 | 灰色为实际值，绿色为预测值 | 预测画在它所指的时刻 `t+h` |
| 节点位置 | 仅为排版 | `relaxed_positions` 只读节点数与种子 |

与 V0.6 的不同：不再有按帧归一化的量；不再有不对应真实量的动画；状态同时用颜色、亮度、大小编码；蓝与红在明度上有差别。

## 4. 示范网络与正式引擎的差别

状态方程相同：`x(t) = (1−α)·x(t−1) + α·tanh(W·x(t−1) + W_in·u(t) + b)`。为了教学清楚，示范网络做了三处简化，页面的“公式与注记”里都有说明：

- 48 个节点；循环矩阵由 `intuitive_lab._network` 生成并归一到谱半径 1，嵌入页面，共 6 组。
- 偏置为 0，使“没有输入”时池子完全静止。
- 输入在 [−1, 1] 内直接乘以输入缩放，不做标准化。

读出任务是预测输入本身的未来 6 步（岭回归，λ = 1e-4，前 70% 拟合，后 30% 留出），对照为持续性基线，与正式实验使用的对照一致。

## 5. 结构

```
rcstudio/lab_web/lab.html      页面：样式、数值引擎、绘制、五步文案（不联网、无外部依赖）
rcstudio/lab_web/__init__.py   与 Qt 无关的宿主函数：页面路径、载荷、调用序列化、消息解析
rcstudio/lab_web_view.py       Qt 宿主：QWebEngineView、主题、真实实验加载
rcstudio/intuitive_view.py     原生回退面板（已修复）
scripts/build_lab_networks.py  重新生成嵌入的示范网络
scripts/check_lab_page.py      无头 Chromium 走查并截图
```

页面与宿主之间只有两条通道：宿主调用 `window.RCLab.*`（参数一律 JSON 序列化）；页面把请求写进文档标题（`rclab:{...}`），宿主监听 `titleChanged`。这样不需要 QWebChannel。

网页画布自带解释，Qt 的悬停帮助卡不在其上弹出。帮助目录中 `rc.echo*` 三条已按新实验室改写，新增 `ui.mode`；两份帮助文档同步更新。

## 6. 原生回退面板的修复

- 三个滑块接线；拖动时合并重算，不再把时间重置为 0。
- 扰动外环改用整段响应的统一刻度。
- 粒子只在播放时移动。
- “拓扑”透镜加强连线显示。
- 滚轮缩放上限收紧到节点不出池。
- `show_run(run_id, focus=False)` 安静加载。
- `gui.py` 补上 `QPointF` 导入。

回退面板的版式、字号和五透镜结构没有重做。
