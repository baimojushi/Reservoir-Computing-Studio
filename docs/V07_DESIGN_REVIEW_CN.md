# RC Studio V0.6 直觉实验室 · 对抗性设计审查

审查对象：`RC-Studio-V0_6-Intuitive-Reservoir-Laboratory` 源码包。
审查问题：这个工作台能否让没有 ESN 背景的人**直观地**建立对回声状态网络的认知；以及用户流程、界面观感和交互手感如何。

## 0. 结论与取证方式

**结论：V0.6 没有达到目标。** 设计意图（一个池子、一条时间轴、固定的视觉语义、数据真实）是对的，但落地有三层问题：两处代码缺陷让核心交互根本不工作；若干视觉编码恰好遮住了最该让人看见的现象；流程上没有把新手带到任何一个“原来如此”的时刻。

取证方式要先说清楚，因为它决定了每条结论的可信度：

| 标记 | 含义 |
|---|---|
| **[执行]** | 实际运行了项目代码得到的结果（数值层直接运行；Qt 层用替身模块执行真实的方法体） |
| **[读码]** | 从源码逻辑直接读出，不依赖运行 |
| **[推算]** | 按绘制代码里的坐标与尺寸做的算术，没有真实渲染 |

审查环境没有 PySide6，V0.6 的原生界面无法渲染。因此凡是“看起来怎样”的判断都是 **[推算]**，需要在 Windows 上复核；凡是“能不能用”的判断都是 **[执行]** 或 **[读码]**。

## 1. 会直接挡住用户的缺陷

| # | 问题 | 证据 | 后果 |
|---|---|---|---|
| 1 | 三个沙盒滑块没有连接任何信号 | **[读码]** `intuitive_view.py` 中只有时间轴滑块调用了 `valueChanged.connect`；`_slider_control` 创建滑块后直接返回 | 拖动谱半径、泄漏率、输入缩放，画面和数值标签都不变。What-if Sandbox 的核心动作是空的 |
| 2 | 侧栏“计算流程”示意图绘制即报错 | **[执行]** `gui.py` 使用 `QPointF` 但未导入；去掉本版补上的导入后执行 `TopologyCanvas.paintEvent`，得到 `NameError: name 'QPointF' is not defined` | 示意图空白，每次重绘向控制台打印一次异常 |
| 3 | 扰动外环按“当前帧”归一化 | **[执行]** 默认沙盒中脉冲后 0 / 40 / 80 步的最大状态差为 0.40 / 4.4e-4 / 3.2e-6，外环强度始终按当帧 95 分位归一；到第 140 步 float32 归零，外环才一起消失 | “扰动会消退”是回声状态网络最核心的现象，被这个编码完全抹平：外环一直满强度，然后突然全灭 |
| 4 | “拓扑”透镜没有绘制分支，“评估”透镜不改变池子 | **[读码]** `paintEvent` 中没有 `lens == "topology"` 的分支；`evaluation` 只影响底栏和右侧文字 | 五个透镜里有两个切换后主画面没有变化，用户无从知道自己切了什么 |
| 5 | 流动粒子与模型时间无关 | **[读码]** `phase` 在暂停时照常累加；粒子走完一条边需要 1/0.75 秒，按 30 步/秒回放相当于 40 个时间步，而模型里一次传递恰好一步 | 暂停时“信号”还在流动；粒子位置不对应任何真实量。它违反了本版自己立下的“画面只画真实数据”的约定 |
| 6 | 即使接上滑块也看不到效果 | **[读码]** `_rebuild_sandbox` 把时间游标重置为 0，而 t = 0 时状态接近零。**[执行]** 单次 `simulate_sandbox` 在审查机上约 124 ms，且在界面线程运行 | 拖动时画面回到一池空白；连续拖动时每一格卡顿一次 |

## 2. 心智模型：画面没有把该教的东西摆出来

一个新手要带走的认知只有五条：输入会在池子里留下一段慢慢消退的回声；池子内部的连线是随机的、而且不训练；每个节点的反应各不相同；学习只发生在读出；三个参数分别管回声长短、反应快慢和输入力度。逐条对照：

- **回声消退**：被第 1 节第 3 条遮住；唯一能看到消退的地方是底部 46 像素高的折线，而且它与“初态差异”共用纵轴。
- **因果链 输入 → 池子 → 读出 → 输出**：**[读码]** 输入权重在数据里（`input_weights`）但从未画出，左侧的 INPUT 标记只是一个装饰圆点；读出是唯一被训练的部分，却藏在下拉框第四项。默认底栏显示的是“初态差异 / 输入脉冲影响”两条诊断曲线，不是输出。新手在默认视图里看不到这台机器在做什么。
- **各不相同**：**[读码]** 沙盒模式下点击节点只多一个圈，右侧面板不给任何该节点的信息。
- **只训练读出**：没有“训练前 / 训练后”的对比，读出权重一出场就已经存在。
- **参数的作用**：**[执行]** 示范任务在 ρ = 0.3 / 0.9 / 1.3 / 1.7 下的留出误差为 0.045 / 0.024 / 0.026 / 0.024。旋钮几乎没有后果，用户学不到“为什么要调”。
- **预测未来**：**[读码]** `y(t+h)` 画在 t 处，于是预测线与输入线几乎重合，“提前”这件事看不出来，看起来像复制。
- **不能动手**：**[读码]** 扰动脉冲固定在第 `steps // 3`（73）步，输入轨上没有标记，用户不能选择何时、何处推一下。

## 3. 文案

- **[读码]** 沙盒模式下每条说明后面都追加一句约 60 字的免责声明（“不代表正式实验成绩”“不构成 ESP 证明”），而 ESP 在此之前从未被解释。新手读到的第一段话，一半是在否定一个他没听过的东西。
- “直觉”级文案仍然以“状态”“驱动”“循环连接”开头，没有先给现象。
- 画布内中英混排的大写标签（`ONE RESERVOIR`、`RECURRENT STATE FIELD`、`READOUT`）对目标读者没有信息量。
- 右侧“实验观察”面板把三个滑块的值原样重复一遍，再加“初态差异末/初 = 0.003”这样的指标。

科学上的谨慎是这个项目的优点，问题在位置：这些限定语应该在需要时可查，而不是挡在主阅读路径上。

## 4. 流程

- **首屏**：**[读码]** 左侧 338–440 像素是完整的训练配置（九个超参数，含岭回归系数与随机种子），上方四张指标卡显示“—”，下方是空的实验表。V0.6 的目标是“从仪表盘转为实验室”，但仪表盘原样围在实验室四周。
- **同名异物**：侧栏“谱半径”与沙盒“谱半径 ρ”、侧栏“随机种子”与沙盒“换一组网络”互不相干，界面没有说明。
- **抢焦点**：**[读码]** 启动时 `_refresh` 自动选中最近一条实验，加载完成后 `_loaded` 把“观察对象”切到真实实验并暂停。已有实验的用户一打开就被带离练习场；训练结束时同样会被打断。
- **课程脱节**：**[执行]** `courses.json` 的 5 门课 37 步中，引用直觉实验室（`rc.echo*`）的步骤为 0。第一课第一步是“先分清两个软件”；“用直觉理解 ESN 参数”一课通过侧栏数字框和二选一问答进行，没有一步让人去拖沙盒。
- **控件形态**：观察对象、透镜、解释层级、数据段、速度全是下拉框，选项不可见；透镜本应是一眼能看全的切换。

## 5. 观感与手感

- **比例** **[推算]**：窗口默认 1360×840 时，实验室标签页约 450 像素高，而其内容（工具栏、参数栏、最小 440 的画布、时间轴、说明）合计约 650。画布取最小高度 440 时，储备池矩形约 640×222，圆盘布局被拉成约 3:1 的椭圆；主角只占窗口高度的四分之一。
- **详情栏溢出** **[推算]**：右侧面板可用高度约 158 像素，默认已有 6–7 行；读出透镜再加 4 行、评估透镜再加 3 行，超出部分被 `break` 静默丢弃。恰恰是切换透镜后新增的数字看不到。
- **字号** **[读码]**：画布内大量使用 8、9 像素的中文。
- **缩放** **[推算]**：滚轮上限 1.42，而节点横向半径系数为 0.43，放大到 1.16 以上节点就会画出池子矩形；验收清单里“滚轮缩放不会让节点离开画布”这一项按代码不成立。
- **布局** **[执行]**：`stable_positions` 的最小间距约为 0.74/√N（撒点后只拒绝过近的点），留下成团和空洞，节点只能画成半径 5 像素。
- **连线** **[执行]**：默认沙盒 371 条边在所有透镜下始终全部画出，是一团毛线。
- **两套色板** **[读码]**：画布（`intuitive_view.LIGHT`）与外壳（`gui.PALETTE`）的底色、主色各差一点。
- **配色**：正负用青绿与暖橙，两者明度接近，色弱或灰度下难分；且状态只用颜色一个通道编码。
- **时间轴**：底部滑块与画布内输入轨、输出轨的横向范围不同，手柄位置与轨上的游标对不齐；不能直接在轨上拖动。

## 6. V0.6 做对了、应当保留的

- 一个池子、一条时间轴，节点身份和位置不随视图变化。
- 明文的视觉语义约定（节点颜色永远是 `x_i(t)`）。
- 沙盒与正式实验隔离；真实实验只读回放。
- 连线抽样方式公开标注。
- 数值层与 Qt 分离并有测试；对 ESP、记忆容量的表述克制。

V0.7 的改版保留了以上全部，见 `docs/V07_LAB_CN.md`。

## 7. 一个过程性的教训

第 1 节的前两个缺陷都不难，之所以流出，是因为界面代码从未被执行过：发布说明里写明了“PySide6 不可用，原生渲染待目标机验收”，而 119 项自动测试没有一项触及界面。只要界面层不能在开发环境里运行，这类问题就会反复出现。V0.7 因此把实验室做成可以在无头浏览器里渲染和走查的网页，并补了两项不依赖 Qt 的静态检查（未导入的 Qt 名称、滑块是否接线）。
