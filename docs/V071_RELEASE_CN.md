# RC Studio V0.7.1 · 科学忠实度与交互修复，并入主干工程

本版做两件事：逐项处理《RC Studio V0.7 · 对抗性复审》提出的问题；把结果并入主干仓库 `Reservoir-Computing-Studio`（上传的主干为 V0.4.0，是 V0.6 的基线）。训练算法、数据隔离、实验数据库、服务端口与鉴权都没有改动。

## 1. 复审问题逐项处理

复审中的两组数字都在本机复现了，修复后的结果用同一批数据重新测量。

| 级别 | 复审指出的问题 | 复现或依据 | 修复 | 修复后实测 |
|---|---|---|---|---|
| P0 | 正式实验的输入端口与输入线使用按窗口最小/最大缩放的值，与模型实际使用的标准化输入不一致 | Mackey–Glass 实验 `u(0)`：原始 0.906786，标准化 −0.104333，页面 +0.078115；1200 帧中 69 帧符号相反 | 分开两套数据：`uModel = (u − 训练均值) / 训练标准差` 驱动输入线；画出来的值是它乘以一个正常数，中线即训练均值。多路输入没有保存模型输入，明确标注为摘要，不画输入线 | 页面取到的模型输入与引擎逐点相差 < 1e-9；显示值与模型值符号不一致 0 帧 |
| P0 | 只用 96 步脉冲响应判断是否平息，把会衰减的模型显示成“不停” | 48 节点、谱半径 0.90、泄漏率 0.10：96 步窗口内未降到阈值；160 步窗口在第 110 步降到阈值以下 | 引擎用 2000 步脉冲响应做判定（`core.classify_echo`），随结构一起下发；页面分三种说法：已观察到衰减、观察窗口不足、窗口内未见衰减。旧版服务的数据只有 96 步时显示“96+ 步，窗口不够长，不能判定” | 同一模型：新数据显示“110 步”；去掉判定字段模拟旧数据，显示“观察窗口不足” |
| P1 | 读出贡献没有正负，看不到抵消 | 示范网络某一时刻：节点正向 +6.42，节点负向 −4.23，直连 −2.50，预测 −0.31 | 读出线按贡献正负着色；池子右侧加两根同刻度的柱子：左柱累加正向项，右柱抵消负向项，落点即预测；说明栏给出同一时刻各项数字 | 各项相加与页面预测相差 < 1e-9 |
| P1 | 输入直连和偏置没有进入读出画面 | 读码：V0.7.0 只画节点贡献线 | 直连项和基准进入同一组柱子；直连项另画一条从输入端口越过池子上方的线。多路输入的直连项无法重建，由“预测 − 其余各项”得出并画成空心 | 正式实验各项相加与保存的预测最大相差 1.5e-3（状态保存为 4 位小数所致） |
| P1 | 正式实验的连接权重被按最大值重新缩放 | 读码：V0.7.0 传入的是 `w / wmax` | 权重按模型数值原样传入；连线亮度 `min(1, 2.2·|W_ij·x_j|)`，选中节点线宽按 `|W_ij|`，示范网络与正式实验同一刻度 | 页面内权重与接口返回值逐个相等 |
| P1 | 分段按钮不跟随时间游标 | 读码：V0.7.0 的按钮状态取固定的第 45 帧 | 按钮、时钟标签、游标取同一个来源；点已载入的段直接跳到起点，未载入的段才向服务读取 | 覆盖训练、验证、测试三段的窗口内逐点一致 |
| P1 | 课程与实验室是两套系统 | 原有 5 门课 37 步里引用实验室的为 0 | 新增课程“00 · 在直觉实验室里认识 ESN”：步骤由实验室已经发生的事件判定，做过的直接通过并引用当时的结果（例如“余波约 33 步后平息”），不要求重做。课程按每步目标自动在“认识 ESN”与“研究工作台”之间切换 | 状态机测试与适配层测试通过；Qt 侧仅用替身执行 |
| P2 | 小屏幕上首个操作位置过低 | V0.7.0 在 390×800 下按钮落在首屏之外 | 窄屏时把当前章节的主操作放在池子右下角 | 360×640 与 390×700 下按钮在首屏内，可用 |
| P2 | 节点不能用键盘选择 | V0.7.0 文档已列为未做 | 池子可获得焦点，方向键在节点间移动，Esc 取消；选中结果同步到无障碍标签 | 走查脚本通过 |

复审还建议让“刚刚发生的事”成为短暂的视觉焦点。本版加了两处，都只在用户操作后出现：训练读出时贡献线从节点长向输出、柱子随之升起；敲击时输入端口出现一圈扩散的环（画在池外，不暗示池内的空间传播）。

### 没有采纳或只部分采纳的建议

- **“持续动态现象”需要附加稳定性诊断支持。** 本版没有新增稳定性诊断，因此第三种状态的措辞停在“这段窗口内未见衰减”，不作“不稳定”的结论。
- **原有 01–05 课程。** 没有改写，只在前面加了 00 课，并让课程自动切换显示方式。把 02 课的参数讲解改为由实验室旋钮驱动，留给下一版。
