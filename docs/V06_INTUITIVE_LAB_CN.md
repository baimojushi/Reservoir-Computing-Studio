# RC Studio V0.6 · Intuitive Reservoir Laboratory

## 1. 产品目标

V0.6 将 RC Studio 的主体验从“参数与图表仪表盘”转为“可操作的储备池计算实验室”。用户始终观察同一个储备池本体，沿一条时间轴追踪输入、状态、读出与预测。

主要受众包括没有 ESN 背景的研究者、交互艺术家和电子毛笔创作者。专业信息保留，但解释顺序先呈现现象，再给出公式与边界。

## 2. 主舞台结构

主画布采用三个连续区域：

1. 输入轨：显示当前实验输入或沙盒输入。
2. 单一储备池：节点身份固定，位置稳定；当前时刻由时间游标定位。
3. 输出轨：真实实验显示真实值/预测值；沙盒在动力学/扰动透镜显示初态差异与脉冲影响，在读出/评估透镜显示一个独立拟合的未来输入示范任务。

节点坐标由 `stable_positions(units, seed)` 生成，且只依赖节点数和布局种子。坐标不读取权重、节点编号排序、脉冲响应重心或读出系数。

历史时间不再画成多个并排圆盘。时间通过统一游标、节点当前状态和底部时间轨迹表达，降低“多个时间截面等于多个网络层”的误读风险。

## 3. 视觉语义契约

| 视觉对象 | 永久含义 | 观察透镜中的变化 |
|---|---|---|
| 节点填充色 | 当前状态 `x_i(t)` 的正负与幅值 | 所有透镜保持不变 |
| 节点位置 | 稳定的排版坐标 | 所有透镜保持不变 |
| 连接线颜色 | 固定递归权重 `W_ij` 的正负 | 所有透镜保持不变 |
| 连接线宽度/透明度 | `|W_ij|` 相对大小 | 所有透镜保持不变 |
| 移动粒子 | 当前递归驱动 `W_ij x_j(t-1)` | 动力学透镜显示 |
| 节点外环 | 相对基线的状态差 `Δx_i(t)` | 扰动透镜显示 |
| 汇聚线 | 当前读出项 `w_i x_i(t)` | 读出透镜叠加，不覆盖节点填充色 |
| 输出轨 | 预测目标、真实值、预测值 | 评估透镜强调时间对齐与误差 |

颜色使用青绿色表示正值、暖橙色表示负值。具体主题色可随明暗主题调整，但变量语义不改变。

## 4. 五种观察透镜

### 动力学

显示真实状态 `x_i(t)`，并用移动粒子提示上一时刻状态通过递归权重对当前更新的驱动。状态方程为：

\[
 x(t)=(1-\alpha)x(t-1)+\alpha\tanh(W_{rec}x(t-1)+W_{in}u(t)+b)
\]

### 拓扑

强调固定循环权重。节点位置只用于避免重叠，拓扑关系由权重矩阵中的真实边定义。画布显示 `shown / total` 和边选择规则。

真实实验接口当前返回按 `|W|` 排序的最强边子集；界面明确标注“显示 |W| 最大的 k/N 条边”。独立沙盒超过渲染上限时采用均匀随机抽样并标注“均匀抽样 k/N”。未显示的边仍参与状态更新。

### 扰动

显示两次运行的节点状态差：

\[
\Delta x_i(t)=x_i^{perturbed}(t)-x_i^{baseline}(t)
\]

自由练习使用同一初始状态，在某一输入时刻增加一个脉冲。真实实验使用模型的标准化单次输入脉冲响应；多通道时所有通道收到相同的标准化脉冲，因此它是受控探针，不代表一次真实毛笔动作。

脉冲响应描述指定扰动在当前模型中的影响轨迹。它不直接等于任务记忆容量，也不单独证明 ESP。

### 读出

保留节点状态填充色，增加每个节点当前 `w_i x_i(t)` 对输出的贡献线。对单变量通用 ESN，利用保存的归一化统计量重建输入直连项和偏置项，并计算重建差。

EBrush 训练轨迹只保存目标角速度摘要，没有保存完整六通道输入向量。因此 EBrush 的直连贡献无法从该轨迹重建，界面明确标注缺失，不用目标角速度摘要伪装成六通道输入。

### 评估

真实值 `y(t+h)` 与预测值沿同一时间游标对齐。预测目标时距 `h` 与 GUI 回放速度、训练耗时和推理延迟分别解释。

预测曲线中未显示预测值的开头区间标记为 Washout（预热）：储备池先建立状态，读出评估从有效区间开始。

## 5. What-if Sandbox

沙盒使用独立的小型 ESN，不连接工作区、不提交训练、不写入正式实验。

沙盒同时拟合一个小型线性读出任务：用输入序列前 70% 训练读出，预测未来 6 步的输入波形，并在后 30% 留出区间显示结果。该示范读出只用于教学，不能代替用户实验的正式预测成绩。

可调参数：

- 谱半径 `ρ`：0.05–1.80。
- 泄漏率 `α`：0.02–1.00。
- 输入缩放：0.05–3.00。

输入预设：正弦、脉冲、阶跃、变频和手绘。

每次参数变化使用同一原始随机矩阵和同一随机种子重新缩放，保证参数对照尽量公平。点击“换一组网络”才改变随机种子。

### 初始状态探针

在同一输入下比较零初始状态和随机初始状态：

\[
 d_{init}(t)=\frac{\|x^{(0)}(t)-x^{(alt)}(t)\|_2}{\sqrt{N}}
\]

这项观察回答“本次输入和时间窗口中，初始状态差异怎样变化”。有限实验不构成 ESP 的数学证明。

### 输入脉冲探针

在同一初始状态和网络参数下，对输入信号某一时刻增加脉冲，比较两条状态轨迹：

\[
 d_{pulse}(t)=\frac{\|x^{(pulse)}(t)-x^{(base)}(t)\|_2}{\sqrt{N}}
\]

这项观察回答“一个输入变化怎样影响后续状态”。衰减更慢不自动意味着任务预测更准确。

## 6. 教学入口

直觉模式先用现象描述；科研模式补充符号、公式和数据来源。两种模式共用同一计算结果。

课程保留阅读、答题和真实界面事件记录。用户可以选择“先探索下一步”，当前步骤保留为未完成；稍后可以返回补齐。答题结果不会限制用户自由操作主界面。

对常见错误心智模型，文案允许明确对比，例如：“多个时间位置表示同一储备池在不同时刻的状态，不是多个串联层。”

## 7. 数据真实性与兼容

- 真实实验的节点状态来自保存的 `traces.npz`。
- 循环边来自模型矩阵 `W`。
- 读出权重来自训练后的 `readout`。
- 读出分解需要输入均值/标准差、目标均值/标准差；V0.6 的 `reservoir_structure` 接口增加这些只读元数据。
- `forecast` 元数据提供预测步长、Washout 和项目标识。
- 旧版数据库、实验记录与训练流程保持兼容；不重新训练历史实验。
